# Security and privacy

Screen Privacy is a convenience screen cover. It does not authenticate identity, block input, lock macOS, or guarantee that every window or screen recording is obscured. Read the [documented limitations](README.md#privacy-and-limitations) before relying on it.

## Report a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/mattivilola/screen-privacy-blur-app/security/advisories/new) for security-sensitive reports. Describe the affected version or commit, expected and actual behavior, and a minimal reproduction. Do not include credentials, camera images, or private screen contents.

Use ordinary GitHub issues for non-sensitive bugs and feature requests. Security fixes are developed on the current `main` branch; there are no separately maintained release branches yet.
